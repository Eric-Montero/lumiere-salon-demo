# Lumière — demo de salón (plan Pro)

Landing page de demostración para un salón de belleza para mujeres.

- Tema oscuro y dorado con botón para cambiar a tema claro
- Español e inglés (botón ES/EN)
- Servicios con precios, galería, testimonios y formulario de citas
- Todos los datos (nombre, teléfono, dirección, redes, precios) son ficticios

Sitio estático: un solo `index.html`, sin build. Se publica en Vercel tal cual.
